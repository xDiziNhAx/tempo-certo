# 🌐 Tempo Certo

## 🎯 Objetivo
Desenvolver um site simples utilizando **HTML, CSS e JavaScript**, com consumo de API e hospedagem gratuita.

## 📋 Conteúdo da Landing Page
- Repositório Git configurado com duas branches: `main` e `develop`.
- Cabeçalho com o nome do projeto.
- Breve descrição/slogan.
- Botão de chamada para ação (CTA) como "Saiba Mais".
- Área de sobre/contato com formulário (nome, email, mensagem).
- Ação do botão CTA em JavaScript (mensagem de agradecimento ou redirecionamento).
- Consumo da API **ViaCep** para consulta de CEP.
- Paleta de cores harmoniosa e fontes apropriadas.

## 🚀 Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- API ViaCep
